# Logarithmic

Logarithmic is a simple app for journaling, planning, and note-taking. It consists of entries in a logbook.

Entries are polymorphic and can fulfill whatever role you need them to. If you want an entry to just store a name, that's fine; if you want to add attributes, you can; rich text content can be attached to entries; and they can have subsections that take the form of other entries if you want them to.

Entries are organized in a spreadsheet-inspired format, where each is placed in a numbered column. Column 0 is intended to be the primary location for content; entries in higher-numbered columns act like headings and subheadings that organize content; and you can build entries out into negative-numbered columns to store smaller ideas and asides. This places entries naturally in roles and relationships to each other.

Logarithmic is inspired by Linear's approach to using initiatives, projects, and issues to manage projects; it just has a more general, less opinionated data model.
